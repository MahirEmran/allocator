static void * hybrid::allocate ( std::size_t  size,
std::size_t  id = 0 
)
static

Allocate size bytes.

Small requests (<= HYBRID_THRESHOLD) try slab first; on failure fall back to the specified arena. Large requests go straight to arena.

Parameters
sizeNumber of bytes to allocate.
idArena index (0-based, must be < NUM_ARENAS).
